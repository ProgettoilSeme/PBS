## PBS — Documentazione

Questa cartella raccoglie documentazione **tecnica** e **operativa** del plugin PBS.

- `ARCHITECTURE.md` — panoramica architettura (DB, UI admin, servizi).
- `CLASSES.md` — indice classi/metodi principali.
- `SCHEMA_MODEL.md` — modello Schema/Fields + groups + component kind.
- `COMPONENTS.md` — standard componenti (ACF→PBS) e regole di mapping.
- `GENERATOR.md` — generazione plugin/servizi gLib-compliant.
- `DELTA.md` — analisi/applicazione delta schema→servizio (policy NO-AUTO DB).
- `TOOLS.md` — tool CLI per issue + bump versione (workflow “issue as doc”).
